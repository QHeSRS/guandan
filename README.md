# 离线掼蛋

单机掼蛋（你和对家 vs 两家电脑），纯网页，无需网络。

## 在 iPhone / iPad 上离线玩
1. 有网时用 Safari 打开本仓库的 GitHub Pages 地址。
2. 点「分享」→「添加到主屏幕」。
3. 从主屏幕图标打开一次（让它把文件缓存好）。之后飞行模式也能玩。

## 在 Mac 上
- 同样可以用 Safari 打开地址后「文件 → 添加到程序坞」；或者直接双击 `index.html` 离线运行。

## 文件
- `index.html` 游戏本体（规则、电脑 AI、界面都在这一个文件里）
- `sw.js` 离线缓存
- `manifest.webmanifest`、图标：添加到主屏幕用
